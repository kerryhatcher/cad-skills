# Evidence for pcb-fab-package

The measured facts of this skill come from temporary fixtures in the accepted B6 container image, and from the pinned Gerber parser named in the mask inspector. The test file of the repository holds the list of checks. Each measured fact has one test. The fixtures for those tests are stored with the repository tests.

The profile records carry the SHA-256 of the stored page they cite. The `fab.py profile` command checks each page hash against the stored bytes.
